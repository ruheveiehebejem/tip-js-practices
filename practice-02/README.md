## Цель работы

Изучить работу с функциями, объектами и массивами в JavaScript. Научиться создавать и изменять объекты, использовать методы массивов, работать с параметрами функций и организовывать код с помощью ES-модулей.

## Структура проекта

- `src/data.js` — исходные данные для выполнения заданий.
- `src/task-service.js` — функции для работы с задачами.
- `src/main.js` — основной сценарий программы.
- `examples/functions-and-references.js` — эксперименты с функциями и ссылками.
- `checks.js` — автоматические проверки.
- `package.json` — настройки проекта и команды запуска.

## Выполненные задания

В ходе практической работы были реализованы следующие функции:

1. `createTask(id, title, priority)` — создание новой задачи.
2. `findTaskById(tasks, id)` — поиск задачи по идентификатору.
3. `getPendingTasks(tasks)` — получение невыполненных задач.
4. `getTaskTitles(tasks)` — получение названий задач.
5. `getTaskStats(tasks)` — получение статистики задач.
6. `addTask(tasks, id, title, priority)` — добавление задачи.
7. `setTaskCompleted(tasks, id, completed)` — изменение статуса задачи.
8. `renameTask(tasks, id, title)` — переименование задачи.
9. `removeTask(tasks, id)` — удаление задачи.

При изменении массива использовались методы `map`, `filter`, `find` и `some`. Исходные массивы не изменяются, для получения обновлённых данных создаются новые массивы.

## Эксперименты с функциями и ссылками

Были выполнены шесть экспериментов.

### Эксперимент 1. Параметры и возвращаемое значение

Проверена работа функции с числами и строками.

Результат:
- `sum(2, 3)` возвращает `5`.
- `sum("2", 3)` возвращает строку `"23"`.

### Эксперимент 2. Тело стрелочной функции

Проверена работа стрелочной функции с фигурными скобками.

В первоначальном варианте отсутствовал `return`, поэтому функция возвращала `undefined`.

После добавления `return` результат вызова `square(4)` стал равен `16`.

### Эксперимент 3. Два имени одного объекта

Проверено копирование ссылки на объект.

Изменение свойства через переменную `alias` изменяет тот же объект, на который ссылается `product`.

Результат:
- `product.stock` — `5`.
- `product === alias` — `true`.

### Эксперимент 4. Копия массива с объектом

Проверено поверхностное копирование массива с помощью оператора spread.

После изменения объекта через копию изменилось и значение в исходном массиве, потому что обе версии содержат ссылку на один объект.

### Эксперимент 5. Копия объекта и порядок свойств

Проверено копирование объекта и порядок перезаписи свойств.

Результат:
- `product.stock` — `3`.
- `first.stock` — `8`.
- `second.stock` — `3`.

### Эксперимент 6. Параметр по умолчанию

Проверена работа параметра функции со значением по умолчанию.

При передаче `undefined` используется значение по умолчанию. При передаче `null` или пустой строки эти значения сохраняются.
