## 4. Модель данных и функции

Каждая задача содержит четыре поля: `id`, `title`, `completed`, `priority`.

- `id` — положительное безопасное целое число.
- `title` — строка длиной от 1 до 100 символов после удаления пробелов по краям.
- `completed` — логическое значение; у новой задачи всегда `false`.
- `priority` — `low`, `medium` или `high`; значение по умолчанию — `medium`.

В `src/task-service.js` реализованы девять функций: создание задачи, поиск по ID, получение невыполненных задач, получение названий, расчёт статистики, добавление, изменение статуса, переименование и удаление.

Функции чтения возвращают найденную задачу, новый массив или объект статистики. Функции изменения возвращают объект с `ok: true` и новым массивом `tasks`. При некорректных данных или отсутствии задачи возвращается `ok: false` и текст ошибки.

**Почему id не равен индексу:** ID — отдельное поле задачи. Например, задача с ID 10 может находиться на позиции 3. Поэтому используется поиск по полю `id`, а не обращение к элементу массива по индексу.

**Почему getTaskStats возвращает число, а не строку с процентом:** вычисления должны возвращать числовое значение. Округление для показа выполняется отдельно с помощью `toFixed(1)`.

**Какие объекты копируются при изменении задачи:** при переименовании и изменении статуса создаётся новый массив и новый объект только для выбранной задачи. Остальные объекты можно оставить без изменений. Исходный массив не изменяется.

## 5. Общий демонстрационный сценарий

Ожидаемые результаты контрольного сценария:

| Этап | Всего / выполнено / осталось / прогресс |
|---|---|
| Исходный набор | 4 / 2 / 2 / 50.0% |
| Добавление id 20 | 5 / 2 / 3 / 40.0% |
| Выполнение id 4 | 5 / 3 / 2 / 60.0% |
| Переименование id 10 | 5 / 3 / 2 / 60.0% |
| Удаление id 7 | 4 / 3 / 1 / 75.0% |

Итоговые идентификаторы: `[1, 4, 10, 20]`. Единственная невыполненная задача имеет ID 20.

Повторное добавление задачи с ID 20 завершается ошибкой, потому что такой ID уже есть. При ошибке текущий массив остаётся прежним. В сценарии отдельно сравниваются исходные данные и сохранённая копия `demoTasks`.
