# Практическая работа №3. Работа с DOM и событиями

**Вариант:** 8  
**Тема индивидуального варианта:** Оформление технической документации.

## 1. Цель работы

Изучить работу с DOM-деревом и событиями в JavaScript. Научиться создавать и изменять HTML-элементы с помощью JavaScript, обрабатывать действия пользователя, использовать делегирование событий и разделять данные приложения и их отображение.

## 2. Используемые технологии

- HTML5;
- CSS3;
- JavaScript (ES Modules);
- DOM API;
- Node.js и npm;
- Git.

## 3. Структура проекта

В проекте используются следующие основные файлы:

- `index.html` — основная HTML-страница;
- `styles.css` — оформление интерфейса;
- `src/data.js` — исходные данные и индивидуальный вариант;
- `src/task-service.js` — функции для работы с задачами;
- `src/task-selectors.js` — фильтрация задач;
- `src/task-view.js` — создание и отображение DOM-элементов;
- `src/main.js` — основная логика приложения;
- `checks/` — автоматические проверки;
- `examples/` — примеры работы с DOM и событиями.

## 4. Выполненные задания

### Задание 1. Подключение данных и сервисных функций

Подключены данные общего набора и индивидуального варианта №8. Использованы функции из предыдущей практической работы для поиска, изменения статуса и удаления задач.

### Задание 2. Фильтрация задач

Реализована функция `getVisibleTasks`, которая возвращает задачи в зависимости от выбранного фильтра:

- `all` — все задачи;
- `pending` — задачи, которые ещё не выполнены;
- `completed` — выполненные задачи.

### Задание 3. Создание DOM-элементов

Реализована функция `createTaskElement`, которая создаёт карточку задачи. В карточке отображаются название, статус, приоритет и кнопки управления.

Для добавления текста используется `textContent`.

### Задание 4. Отображение списка и статистики

Реализованы функции:

- `renderTaskList` — отображение списка задач;
- `renderSummary` — отображение общей статистики;
- `renderEmptyState` — отображение сообщения, если список пуст или по выбранному фильтру нет задач.

### Задание 5. Обработка событий

Реализована обработка нажатий на кнопки изменения статуса и удаления задач.

Использовано делегирование событий: обработчик установлен на общий список задач. Для определения действия используются `data-action` и `data-task-id`.

### Задание 6. Работа фильтров

Добавлена обработка нажатий на кнопки фильтрации. При выборе фильтра список перерисовывается, а активная кнопка получает соответствующий статус.

### Задание 7. Индивидуальный вариант №8

Тема: «Оформление технической документации».

Создан индивидуальный набор из шести задач:

| ID | Название задачи | Статус | Приоритет |
|---|---|---|---|
| 11 | Составить структуру технической документации | Выполнена | Высокий |
| 23 | Описать назначение программных модулей | Выполнена | Средний |
| 37 | Подготовить инструкцию по установке | Выполнена | Низкий |
| 41 | Оформить описание функций | В работе | Средний |
| 58 | Добавить примеры использования | В работе | Высокий |

Для индивидуального варианта проверено изменение статуса задачи с ID 23 и удаление задачи с ID 37.

## 5. Проверка работы приложения

### 5.1. Проверка общего набора

Проверен следующий сценарий:

1. При запуске отображаются 4 задачи.
2. Выбирается фильтр невыполненных задач.
3. Изменяется статус задачи с ID 4.
4. Выбирается отображение всех задач.
5. Удаляется задача с ID 7.
6. Проверяется фильтр невыполненных задач.
7. Изменяется статус задачи с ID 1.
8. Удаляются оставшиеся задачи.

Результат: все операции выполняются, статистика обновляется после каждого изменения.

### 5.2. Проверка индивидуального варианта

Проверено отображение шести индивидуальных задач, работа фильтров, изменение статуса и удаление задачи.

Результат: приложение корректно отображает индивидуальный набор и обновляет статистику после действий пользователя.

| № | Эксперимент | Ожидаемый и полученный результат |
|---|---|---|
| 1 | Создание элемента через `document.createElement` | Создаётся новый HTML-элемент. |
