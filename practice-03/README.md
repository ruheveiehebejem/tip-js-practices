## Запуск

Из папки practice-03 выполнить:

    npm run check:service
    npm start

Затем открыть адрес сервера http://127.0.0.1:5503/ и страницы examples/dom-events.html, checks.html, а также index.html?dataset=variant. Устанавливать дополнительные зависимости не требуется. Остановка — Ctrl+C.

## Перенос из ПР2 и структура

Из ПР2 перенесены девять функций предметной логики и общий набор. task-selectors.js отвечает за фильтрацию. task-view.js создаёт DOM-карточки и обновляет сводку. main.js хранит текущее состояние, назначает делегированные обработчики один раз и связывает действия пользователя с функциями сервиса.

## Проверки и собственные случаи

Сервисные проверки запускаются командой npm run check:service. Браузерный набор запускается автоматически на странице checks.html и содержит 36 готовых сценариев. Вставить ниже фактические результаты обоих запусков; до запуска они не считаются подтверждёнными.

- Сервисные проверки: вставить реальный вывод терминала.
- Браузерные проверки: вставить реальный текстовый протокол со страницы checks.html.
- Скриншот интерфейса: добавить после собственного запуска.

Собственные проверки для ручного выполнения:
1. Удалить все записи: сводка должна стать нулевой, появится сообщение о пустом списке.
2. Нажать на заголовок карточки: данные не должны измениться.
3. В DevTools заменить data-task-id на 4abc и нажать действие: должно появиться сообщение об ошибке, данные останутся прежними.
