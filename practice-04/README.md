## Реализация updateTask

Функция проверяет положительный безопасный ID и наличие задачи, затем использует проверку полей создания, чтобы нормализовать название и проверить приоритет. Возвращается новый массив и новый объект для изменённой задачи. Меняются только title и priority; id и completed сохраняются. Исходный массив и его объекты не изменяются.

## Проверка формы

В режиме создания ID преобразуется в число, проверяется на положительность, безопасную целочисленность и уникальность. Название после trim должно содержать от 1 до 100 символов. Приоритет может быть только low, medium или high.

В режиме редактирования ID берётся из editingId, поэтому поле ID блокируется и не участвует в отправляемом FormData. Изменение не сбрасывает статус выполнения. При ошибке показываются только сообщения полей; список и storage не меняются.

| Сценарий | Ожидаемый результат | Фактический результат |
|---|---|---|
| Корректное создание | Новая запись добавлена и сохранена. | Заполнить после запуска. |
| Повторный ID | Отказ, поле ID отмечено, запись не сохранена. | Заполнить после запуска. |
| Название из пробелов | Отказ прикладной проверки. | Заполнить после запуска. |
| Пустая форма | Отказ нативной проверки HTML. | Заполнить после запуска. |
| Редактирование | Меняются title и priority, completed сохраняется. | Заполнить после запуска. |
| Отмена редактирования | Возврат к пустой форме создания. | Заполнить после запуска. |

## Локальное хранение

В storage используется версия схемы 1 и оболочка `{ version: 1, tasks: [...] }`. Перед чтением и сохранением проверяется весь список: типы и значения полей, длина и нормализация названия, допустимый приоритет, безопасный ID и уникальность ID.

- Если ключ отсутствует, загружается независимая копия начального набора.
- Если JSON и схема корректны, список восстанавливается из storage.
- Если JSON повреждён, версия или схема неверны либо storage выбрасывает исключение, приложение использует начальный набор и показывает предупреждение.
- Сохраняются только успешные изменения задач: add, update, toggle и delete.
- Выбор фильтра и открытие формы редактирования сами по себе не записываются.
- Сброс удаляет только ключ текущего набора и возвращает начальные данные; исходный список сразу повторно не записывается.
