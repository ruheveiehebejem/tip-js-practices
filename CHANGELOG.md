# История изменений

## 1.0.0

### Добавлено

- Health endpoints: liveness без обращения к БД и readiness с проверкой PostgreSQL.
- Структурированное журналирование HTTP-запросов и заголовок `X-Request-Id`.
- Маскирование чувствительных значений в логах.
- Ограничение размера JSON-тела через `JSON_BODY_LIMIT_BYTES` и ответ HTTP 413 при превышении.
- Graceful shutdown по SIGINT и SIGTERM с закрытием HTTP-сервера и пула PostgreSQL.
- Dockerfile, Docker Compose, smoke-проверка и GitHub Actions workflow.
- Интеграционный тест варианта 8 для ответа 413.

### Изменено

- Настроена конфигурация окружения и безопасные значения параметров по умолчанию.
- Контейнерная база и CI используют PostgreSQL 18.
- Проверка релиза разделена на quality gate, подготовку базы, DB-тест и отдельный smoke уже запущенного API.
- Корневой README дополнен отчётом ПР14 и ссылками на предыдущие практики.

### Исправлено

- Обработка результата UPDATE после конкурентного удаления задачи: при отсутствии строки маршрут возвращает 404 `TASK_NOT_FOUND`.
- Smoke-проверка сверяет фактический контракт readiness и проверяет начальный фильтр варианта 8.
- Релизная проверка больше не запускает DB-тест без предварительной подготовки отдельной учебной базы.
